# 2S Engenharia e Construtora Itu — Prévia conceitual

Site institucional estático e responsivo, sem contadores fictícios nem numeração decorativa, criado como **demonstração comercial independente**. Ainda não é um site oficial da empresa.

## Como visualizar

Abra `index.html` no navegador, ou publique os arquivos na raiz (`/`) da branch `main` com GitHub Pages. **Não há build, Node ou dependências para instalar.**

## Organização

- `index.html`: conteúdo e estrutura da página;
- `style.css`: visual, animações e responsividade;
- `script.js`: menu mobile, tratamento de rolagem e animações;
- `assets/favicon.svg`: ícone provisório.
